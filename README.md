# Real Interview Coding Questions 🚀

A collection of coding questions asked in real technical interviews, along with solutions, explanations, and approaches to solving them.

## 🎯 Objective

- Practice coding questions from actual interview experiences.
- Strengthen problem-solving and logical thinking skills.
- Prepare for technical interviews and job switches.
- Maintain a structured collection of questions for revision.

## 🛠️ Technologies Covered

- **Python** – Programming fundamentals, OOP, data structures, algorithms, and coding problems.
- **SQL** – Queries, joins, subqueries, window functions, and query optimization.
- **Angular** – TypeScript, components, services, RxJS, and practical coding questions.
- **FastAPI** – REST APIs, exception handling, validation, and API development.
- **GenAI** – LLMs, LangChain, LangGraph, and AI application concepts.
- **DSA** – Arrays, strings, searching, sorting, and other problem-solving patterns.

## 📝 Question Format

Each question may include:

1. **Interview Question** – The original question or a clear summary.
2. **Company / Role** – Where it was asked, if known.
3. **Problem Statement** – What the problem requires.
4. **Solution** – Working code or SQL query.
5. **Explanation** – Step-by-step logic.
6. **Example Input / Output** – To demonstrate the result.
7. **Complexity Analysis** – Time and space complexity, where applicable.
